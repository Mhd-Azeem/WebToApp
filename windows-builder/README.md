# Windows Builder

Planned desktop application for Windows.

## Responsibilities

- Create/edit WebToApp configuration files.
- Select website URL, application name, package name, icon and theme.
- Enable/disable supported native modules.
- Generate an Android Studio project from `android-template`.
- Launch local Gradle builds when Android SDK/JDK are installed.
- Export projects for GitHub Actions builds.

Initial implementation will prioritize a stable GUI and deterministic project generation.
