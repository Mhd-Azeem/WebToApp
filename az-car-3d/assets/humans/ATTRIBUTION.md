# Human asset attribution

Quaternius created both humanoid base meshes, skeletons and original textures.
The game uses the male and female humanoid bases from the free Universal Base
Characters kit. Both use movement and seated clips from the free Universal
Animation Library and Universal Animation Library 2. These packs are CC0 1.0.
The sources were obtained from the public mirror below.

- [Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html)
- [Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html)
- [Universal Animation Library 2](https://quaternius.com/packs/universalanimationlibrary2.html)
- [Source file mirror](https://github.com/NafisRayan/Animate-Rigged-Humanoid-No-Blender)
- [CC0 1.0 dedication](https://creativecommons.org/publicdomain/zero/1.0/)

AZ Car 3D retargets the animation tracks, embeds downscaled base-color textures
and paints original everyday clothing onto the body textures. Both GLBs use
skinned meshes and a skeletal AnimationPlayer. The source meshes have stylized
proportions and the clothes use the mesh silhouette of the bases.
