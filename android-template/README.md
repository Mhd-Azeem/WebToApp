# Android Template

Reusable Kotlin Android application template generated/configured by WebToApp.

Target capabilities:

- Android WebView
- adaptive phone/tablet layout
- auto, portrait, and landscape orientation modes
- edge-to-edge and display-cutout handling
- JavaScript, DOM storage and cookie persistence
- back navigation
- file upload/download
- camera/microphone/location permissions
- fullscreen HTML5 video
- network/offline handling
- pull-to-refresh
- share and external-link routing
- modular optional features

Build baseline refreshed for the WebToApp Android builder.
